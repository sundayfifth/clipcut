# clipcut

แปลงคลิปแนวนอน (16:9) เป็น 9:16 สำหรับ TikTok แบบกึ่งอัตโนมัติ

---

## ติดตั้ง (ทำครั้งเดียว)

### บน Mac

1. ดาวน์โหลดโฟลเดอร์นี้ทั้งอัน
2. **ดับเบิลคลิก `setup.command`**
3. รอจนขึ้นว่า "ติดตั้งเสร็จแล้ว"

> ถ้า Mac ขึ้นว่า *"ไม่สามารถเปิดได้เพราะมาจากผู้พัฒนาที่ไม่ระบุตัวตน"*
> ให้คลิกขวาที่ไฟล์ → เลือก **Open** → กด **Open** อีกครั้ง

### บน Windows

1. ดาวน์โหลดโฟลเดอร์นี้ทั้งอัน
2. **ดับเบิลคลิก `setup.bat`**
3. รอจนขึ้นว่า "ติดตั้งเสร็จแล้ว"

⚠️ **บน Windows จะไม่มี checklist กราฟฟิก และไม่มีการแนะนำแถบซับ**
เพราะการอ่านข้อความไทยในเฟรมใช้ Apple Vision ซึ่งมีเฉพาะบน Mac
ส่วนอื่น (แบ่งซีน · ตัดสิน crop/ย่อ · ปรับกรอบ · ฟังเสียง · สร้างไฟล์) ใช้ได้ครบ

---

## ใช้งาน

1. เอาคลิปไปวางในโฟลเดอร์ `media/input/`
2. **ดับเบิลคลิก `start.command`** (Mac) หรือ **`start.bat`** (Windows)
3. เบราว์เซอร์จะเปิดขึ้นมาเอง
4. เลือกคลิปจากรายการทางซ้าย
5. รอวิเคราะห์สักครู่ (คลิป 1 นาทีใช้เวลาราว 1-2 นาที)
6. ตรวจแต่ละซีน แก้ตรงที่ไม่เห็นด้วย แล้วกด **สร้างไฟล์ 9:16**

ไฟล์ที่ได้อยู่ใน `media/output/<ชื่อคลิป>/`

**ปิดโปรแกรม**: ปิดหน้าต่างสีดำ (Terminal) ที่เปิดค้างไว้

## เครื่องมือช่วยอะไร

| ช่วยเรื่อง | หมายความว่า |
|---|---|
| **แบ่งซีนให้เอง** | ไม่ต้องนั่งไล่ดูคลิปหาจุดตัด เลื่อนเมาส์ผ่านภาพก็เห็นทั้งซีน |
| **เลือกวิธีตัดให้** | บอกว่าซีนไหนตัดเต็มจอตามตัวคนได้ ซีนไหนควรย่อทั้งภาพ + ให้ดูผลลัพธ์ 9:16 จริง |
| **ปรับกรอบเองได้** | ลากบนภาพเพื่อขยับกรอบ · `⌥`+ล้อ เพื่อซูม |
| **บอกกราฟฟิกที่หาย** | อ่านข้อความไทยในเฟรม แล้วบอกว่าอันไหนจะโดนตัด (เฉพาะ Mac) |
| **ฟังก่อนตัด** | ฟังเสียงซีนนั้น หรือฟังว่าถ้าตัดซีนนี้ออก เสียงจะสะดุดมั้ย |

**ยังต้องทำเองต่อ**: ทำกราฟฟิกที่หายไปใน CapCut · ใส่ซับด้วย skill `subtitle-align`

## คีย์ลัด

กดที่การ์ดซีนก่อน แล้วใช้

| ปุ่ม | ทำอะไร |
|---|---|
| `Space` | เลือก / ไม่เลือกซีนนี้ |
| `C` | ตัดเต็มจอ |
| `P` | ย่อทั้งภาพ |
| `←` `→` | ย้ายไปการ์ดถัดไป |
| `⌘Z` | ย้อนกลับ |
| `⌥` + ล้อเมาส์ | ซูมกรอบ |

## เจอปัญหา

| อาการ | ทำยังไง |
|---|---|
| ไม่เห็นคลิปในรายการ | ตรวจว่าไฟล์อยู่ใน `media/input/` และเป็น .mp4 / .mov / .mkv / .webm |
| แบ่งซีนถี่เกินหรือหยาบเกิน | เปลี่ยน "ความละเอียดในการแบ่งซีน" ทางซ้าย แล้วเลือกคลิปใหม่ |
| ซับเดิมยังติดมา | ในแผง "ตัดซับ / โลโก้เดิม" เลื่อนหาเฟรมที่เห็นซับ แล้วตั้งแถบ |
| หน้าเว็บค้าง | ปิดแท็บแล้วเปิด http://127.0.0.1:8000 ใหม่ |
| `setup` แจ้งว่าไม่พบ Python | ติดตั้งจาก https://www.python.org/downloads/ (Windows: ติ๊ก "Add Python to PATH") |
